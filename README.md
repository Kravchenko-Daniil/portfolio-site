# portfolio-site

Personal site / online CV — live at **[kravchenko-daniil.site](https://kravchenko-daniil.site)**.

## Stack

React 19 · TypeScript · Vite · Tailwind (CDN) · Framer Motion

Single-page app, sections: Hero, About, Career, Work, Achievements, Operate, Goals, Now, Life, Story, Highlights, Contact.

## Run locally

```bash
npm install
npm run dev
```

Deploy: `npm run build` → static output in `dist/`.
